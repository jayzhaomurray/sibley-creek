Audit-findings files generated by the cross-model audit workflow land here.
Shape A (page/component audit): `<basename>-by-<auditor>-<YYYY-MM-DD>.md`,
where auditor is whichever model is NOT the leader for that task.
Shape C (working diff audit): `working-diff-by-<auditor>-<YYYY-MM-DD>-<HHmm>.md`.
These files are produced by `npm run audit` and `npm run audit-diff`.
The pre-push hook (`.githooks/pre-push`) checks that at least one of them
was committed alongside any push that touches substantial paths.
