# R1 Editorial Task Workflow

Use this for routine reader-facing text that relies on established data and source conventions.

## When To Use

- release blurbs;
- dashboard copy;
- chart captions;
- section introductions;
- routine analytical summaries;
- copy edits that preserve existing claims.

## Process

1. Identify the surface: homepage, topic page, chart, blurb, research note, or subscriber artifact.
2. Identify the data or source behind each numerical claim.
3. Draft or revise the text.
4. Apply the three editorial gates:
   - fact-check;
   - style polish;
   - surface fit.
5. Flag any claim that should be escalated to R2.

## Required Output

- final text or file edits;
- source basis for numerical claims;
- confirmation of the three editorial gates;
- unresolved questions, if any.

## Escalate To R2 When

- the task introduces a central claim;
- there is ambiguous interpretation;
- the conclusion depends on non-primary source material;
- the text implies causality or policy judgment;
- the result could anchor a deep dive.
