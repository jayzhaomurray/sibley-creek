# Claim Card

## Claim

Write the exact claim in reader-facing language.

## Status

Hypothesis / Verified / Disputed / Killed

## Surface

Dashboard / Topic page / Deep dive / Subscriber note / Internal only

## Source Basis

- Primary source, pipeline output, chart, or calculation.

## Supporting Evidence

- Data points, chart, table, or source passages.

## Alternative Explanations

- Plausible alternatives that weaken or qualify the claim.

## Falsification Trigger

- What evidence would make this claim wrong or materially weaker?

## Required Caveat

- What caveat must travel with the claim?

## Review Status

Not reviewed / Fact-checked / Style-polished / Surface-approved
