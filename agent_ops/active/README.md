# Active Work

This directory tracks active workstreams at the operating level.

It is not a replacement for `STATUS.md`. `STATUS.md` remains the top-level project dashboard. Files here are model-facing control notes that help agents avoid rediscovering context or improvising process.

Each active workstream should have one short control file with:

- purpose;
- current risk level;
- owner model;
- reviewer model, if any;
- current artifact locations;
- next decision needed from Jay;
- open risks.

Only create detailed control files for active work. Do not inventory the whole repo.
