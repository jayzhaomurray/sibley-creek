Cross-audit research-memo artifacts land here, generated by `npm run cross-audit`.
Each task gets its own subdirectory named by task slug: `<task-slug>/`.
Inside each: `spec.md` (task definition), `claude-pass.md` (Claude's audit pass),
`codex-pass.md` (Codex's audit pass), `synthesis.md` (reconciled findings).
These are internal working documents; the final binding findings go to
`editorial/audit_findings/` per the Shape A/C naming convention.
